# Лабораторная работа №6: Библиотека работы с текстовыми файлами

## Вариант 2: Вырезание строк по диапазону (cut по строкам)

### Описание
Реализована библиотека `txtfile` для выполнения операций над текстовым файлом.

Функции библиотеки:
- `read_file` — считывает текстовый файл в массив строк
- `free_lines` — освобождает память массива строк
- `print_lines` — выводит массив строк в stdout
- `cut_lines` — выделяет диапазон строк по номерам

### Сборка
make

### Запуск
./cut_file <имя_файла> <начало> <конец>

### Пример
./cut_file data/input.txt 2 4

### Требования
- Используется собственная библиотека libft
- Запрещены <stdio.h>, <stdlib.h>, <string.h>
- Разрешены: open, close, read, write, malloc, free
